# Traffic Light Controller using NE555 Timer and CD4017

## Overview
This project implements an automatic traffic light controller using the NE555 Timer and CD4017 Decade Counter in Proteus. The NE555 generates clock pulses while the CD4017 activates LEDs sequentially to simulate a traffic signal.

## Features
- Automatic traffic light sequence
- Designed in Proteus
- Uses NE555 as clock generator
- Uses CD4017 decade counter
- Low-cost hardware implementation

## Components
- NE555 Timer IC
- CD4017 Decade Counter
- LEDs
- Resistors
- Capacitors
- Power Supply

## Software
- Proteus 8 Professional

## Working
The NE555 operates in astable mode and generates clock pulses. These pulses are applied to the CD4017, which sequentially activates the outputs connected to the Red, Yellow, and Green LEDs.

## Applications
- Traffic signal demonstration
- Digital electronics learning
- Embedded systems basics
